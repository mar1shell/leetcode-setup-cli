# leetcode-setup-cli

Small CLI to initialize a LeetCode workspace quickly with the problem descriptions so you can focus on solving problems and submitting them directly to your GitHub.

**Summary**

- **Purpose:** Scaffolds a LeetCode project and helper files.
- **Language:** Python

**Requirements**

- Python 3.8+
- See `requirements.txt` for dependencies

**Install**

```bash
python3 -m pip install -r requirements.txt
```

**Usage**

```bash
python3 inileet.py
```

Runs the initializer to create or configure files for tracking LeetCode solutions.

**Files**

- `inileet.py` — main script
- `requirements.txt` — dependencies
